# Data Detective v3 — Fast Projector Layout

Run:
`pip install -r requirements.txt`
`streamlit run app.py`

Teacher/projector: `http://localhost:8501/`
Student test view: `http://localhost:8501/?role=student`

The projector uses a fixed two-column teaching layout:
LEFT = dataset + only the number of joined pairs.
RIGHT = stage-specific question, answer counts, discussion prompt, share wall, and reveal.

The dataset follows the uploaded PPT mini challenge: Jan 75, Feb 80, Mar 78, Apr 85, May 90.
